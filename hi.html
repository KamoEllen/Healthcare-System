The 5 Orchestration Questions

    
Answer these before designing any feature operation.

    

      

        
1. Trigger — What starts it?

        
What event or action kicks off this operation?

        
e.g. "User clicks Submit", "Cron job fires at midnight", "Webhook received from Stripe"

      

      

        
2. Prerequisites — What data must we read first?

        
What existing records do you need to load before writing anything?

        
e.g. "Load the workspace to check it exists", "Verify user has the required permission role"

      

      

        
3. Sequence — What is the exact order of writes?

        
List every database write / external call in the order they must happen.

        
e.g. "1. Insert invoice row. 2. Update account balance. 3. Send confirmation email."

      

      

        
4. Branches — What if/else conditions exist?

        
Every conditional path that changes the sequence.

        
e.g. "If plan = Free → reject. If already subscribed → update instead of insert."

      

      

        
5. Failure — What happens if step N fails?

        
For each write, what is the rollback or compensation strategy?

        
e.g. "Wrap steps 1–3 in a DB transaction. If email fails, log + add to retry queue."
